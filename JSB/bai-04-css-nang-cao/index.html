1. Độ ưu tiên (Specificity)

Khi nhiều đoạn CSS cùng nhắm vào 1 phần tử và "cãi nhau" (ví dụ cái bảo màu đỏ, cái bảo màu xanh), trình duyệt sẽ nghe theo selector mạnh hơn.

🏆 Bảng xếp hạng sức mạnh

🥇 !important – "Quyền lực tối thượng" (hạn chế dùng!)

🥈 Inline style (style="...") – 1000 điểm

🥉 #id – 100 điểm

4️⃣ .class – 10 điểm

5️⃣ tên thẻ (p, h1, div...) – 1 điểm

🧠 Dễ nhớ: Thẻ là học sinh, class là lớp trưởng, id là thầy cô, inline là hiệu trưởng. Ai chức to hơn thì người đó quyết!

Ví dụ 1: Ai thắng?

h4          { color: red;   }   /* 1 điểm   */
.chu-xanh   { color: blue;  }   /* 10 điểm  */
#chu-la     { color: green; }   /* 100 điểm */

<h4 class="chu-xanh" id="chu-la">Tôi màu gì?</h4>

👉 Tôi màu gì? → Màu XANH LÁ vì #id có điểm cao nhất.

👉 Còn tôi chỉ có class → màu XANH DƯƠNG.

👉 Tôi chẳng có gì → màu ĐỎ của selector h4.

Ví dụ 2: Cộng điểm

.hop p        { color: orange; }  /* 10 + 1 = 11 điểm */
.hop .dong    { color: purple; }  /* 10 + 10 = 20 điểm → THẮNG */

👉 Dòng này màu TÍM vì .hop .dong (20 điểm) > .hop p (11 điểm).

Ví dụ 3: Bằng điểm thì sao?

.the-a { color: red; }
.the-a { color: deeppink; }   /* viết SAU → THẮNG */

👉 Bằng điểm thì CSS viết sau cùng sẽ thắng → màu hồng đậm.

💡 Mẹo: dùng Inspect (F12), CSS nào bị gạch ngang trong tab Styles là CSS đã thua.

2. Tính kế thừa (Inheritance)

Giống như con cái thừa hưởng màu mắt, màu tóc từ bố mẹ, thẻ con cũng tự động nhận một số thuộc tính CSS từ thẻ cha.

✅ ĐƯỢC kế thừa (thường liên quan đến chữ):
color, font-size, font-family, font-weight, text-align, line-height

❌ KHÔNG kế thừa (thường liên quan đến hộp):
border, padding, margin, width, height, background-color

Thử nghiệm

.cha {
    color: #2F9E44;        /* ✅ con sẽ thừa hưởng */
    font-style: italic;    /* ✅ con sẽ thừa hưởng */
    border: 3px solid red; /* ❌ con KHÔNG thừa hưởng */
    padding: 15px;         /* ❌ con KHÔNG thừa hưởng */
}
Đây là thẻ CHA (có viền đỏ)

Đây là thẻ CON: chữ cũng xanh, cũng nghiêng (kế thừa) nhưng KHÔNG có viền đỏ riêng.

Từ khóa inherit – ép kế thừa

Thẻ a có màu xanh dương mặc định nên không nhận màu từ cha. Muốn nó theo màu cha:

.menu-cam a {
    color: inherit;   /* lấy màu giống thẻ cha */
}

Đoạn văn màu cam có link mặc định và link dùng inherit.

3. CSS Positioning – Định vị phần tử

Thuộc tính position quyết định cách một phần tử được đặt trên trang. Đi kèm là top, right, bottom, left để dịch chuyển.

a) position: static (mặc định)

Phần tử nằm theo thứ tự bình thường. top/left không có tác dụng.

b) position: relative (tương đối)

Dịch chuyển so với vị trí cũ của chính nó. Chỗ cũ vẫn được giữ nguyên (để lại khoảng trống).

.o-relative {
    position: relative;
    top: 20px;     /* đẩy từ trên xuống 20px  */
    left: 60px;    /* đẩy từ trái sang 60px   */
}

c) position: absolute (tuyệt đối)

Phần tử "bay" ra khỏi dòng chảy, không giữ chỗ cũ, và định vị theo thẻ cha gần nhất có position khác static (thường đặt cha là relative).

🧠 Công thức vàng: Cha relative – Con absolute.

.the-san-pham { position: relative; }  /* CHA làm mốc  */
.nhan-hot {
    position: absolute;                 /* CON bay theo cha */
    top: -12px;
    right: -12px;
}

Nhãn "HOT" được gắn vào góc trên bên phải nhờ absolute.

d) position: fixed (cố định)

Dính chặt vào màn hình, cuộn trang thế nào cũng không chạy. 👉 Nhìn góc dưới bên phải: nút "⬆ Lên đầu" chính là position: fixed!

e) position: sticky (dính khi cuộn)

Bình thường như static, nhưng khi cuộn tới vị trí đã định thì dính lại. Hãy cuộn trong hộp bên dưới:

f) z-index – Ai nằm trên?

Khi các phần tử chồng lên nhau, z-index lớn hơn sẽ nằm trên. (Chỉ có tác dụng khi có position khác static.)

z-index: 1
z-index: 3
z-index: 2

📋 Tóm tắt

  • static: mặc định, nằm yên theo thứ tự.
  • relative: dịch so với chỗ cũ, vẫn giữ chỗ.
  • absolute: bay theo cha gần nhất có position, không giữ chỗ.
  • fixed: dính vào màn hình.
  • sticky: dính lại khi cuộn tới.
