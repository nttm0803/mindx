🧩 Cài đặt Extension trong VS Code

Extension (tiện ích mở rộng) giống như "phụ kiện" cho VS Code: cài thêm vào để VS Code thông minh hơn, giúp mình code nhanh hơn và ít lỗi hơn.

Cách cài 1 extension (4 bước)

  1. Mở VS Code.
  2. Bấm vào biểu tượng Extensions (4 ô vuông) ở thanh bên trái, hoặc nhấn Ctrl + Shift + X.
  3. Gõ tên extension vào ô tìm kiếm.
  4. Bấm nút Install màu xanh. Xong!

Các extension nên cài

  • Live Server (tác giả Ritwick Dey) ⭐ Quan trọng nhất
    • Công dụng: mở trang web trên trình duyệt và tự động tải lại mỗi khi bấm lưu (Ctrl + S).
    • Cách dùng: chuột phải vào file HTML → chọn Open with Live Server, hoặc bấm nút Go Live ở góc dưới bên phải.
  • Prettier - Code formatter
    • Công dụng: tự động căn chỉnh thụt lề cho code gọn gàng, đẹp mắt.
    • Bật tự format khi lưu: vào File → Preferences → Settings, tìm "format on save" → tick ✅.
    • Tìm tiếp "default formatter" → chọn Prettier - Code formatter.
  • Auto Rename Tag
    • Công dụng: sửa thẻ mở thì thẻ đóng tự sửa theo. Ví dụ đổi <h1> thành <h2>, thẻ </h1> cũng tự thành </h2>.
  • Material Icon Theme
    • Công dụng: thêm icon đẹp cho từng loại file, nhìn là biết file nào là HTML, CSS, ảnh.
  • Vietnamese Language Pack (không bắt buộc)
    • Công dụng: chuyển giao diện VS Code sang tiếng Việt.

⌨️ Phím tắt "thần thánh" nên nhớ

  • ! + Tab: tạo nhanh khung HTML (tính năng Emmet có sẵn, không cần cài).
  • Ctrl + S: lưu file.
  • Shift + Alt + F: format (căn chỉnh) code. Trên Mac: Shift + Option + F.
  • Ctrl + /: biến dòng đang chọn thành chú thích (comment).
  • Alt + ↑ / ↓: di chuyển dòng code lên / xuống.
  • Shift + Alt + ↓: nhân bản dòng code xuống dưới.
  • Ctrl + B: ẩn / hiện thanh thư mục bên trái.

✅ Tự kiểm tra

  1. Mở file này bằng Live Server.
  2. Sửa chữ "Tự kiểm tra" thành tên của em rồi bấm Ctrl + S.
  3. Trình duyệt tự cập nhật? → Em đã cài thành công! 🎉
