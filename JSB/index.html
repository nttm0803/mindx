🧑‍💻 Khóa học Web cơ bản

HTML & CSS cho học sinh lớp 8 – 11. Chọn buổi học:

Bài 1 – Cài đặt VS Code Extension
Cài Live Server và các extension cần thiết để viết code. Bài 2 – HTML cơ bản
Cấu trúc HTML, danh sách, đường dẫn, hình ảnh, thẻ lồng nhau, website và webpage. Dự án: Portfolio. Bài 3 – CSS cơ bản
Thuộc tính cơ bản, Selectors, Inspect, Box Model. Dự án: MindX Page. Bài 4 – Specificity, Inheritance, Positioning
Độ ưu tiên, tính kế thừa, định vị phần tử, ôn tập kiểm tra. Dự án: The Flag. Bài 5 – Display, Responsive, Flexbox
display, media queries, flexbox. Thực hành: ShopTeen. 🌟 Website tổng hợp – Giới thiệu cá nhân
Vận dụng kiến thức Bài 2 → 5. Bài 6 – Framework, Bootstrap, Web Design
Framework, Bootstrap, Web Design & Color Theory. Dự án: Dog Social (phần 1). Bài 7 – Typography, Phân cấp bố cục, Attention
Chọn font chữ, phân cấp bằng kích thước – vị trí – màu sắc, quản lý sự chú ý trong UI. Thực hành: thẻ sự kiện. 🐾 Dự án Dog Social
Trang giới thiệu ứng dụng cho chú chó, làm bằng Bootstrap qua 6 bước. Vận dụng kiến thức Bài 6. Bài 8 – Form và Input
Thẻ form (action, method GET/POST), các kiểu input, label, select, textarea, kiểm tra dữ liệu. Thực hành: form đăng nhập, trang thanh toán ShopTeen.
