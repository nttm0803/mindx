# Tin Xanh - Trang tin tức môi trường

Website tin tức 3 trang dành cho học sinh, dùng HTML, CSS và Bootstrap 5 (cần Internet để tải Bootstrap, Bootstrap Icons và Google Fonts).

| Trang | Nội dung |
|---|---|
| `index.html` | Carousel 3 tin nổi bật + "Đọc nhiều", 3 chuyên mục: Rác thải, Nguồn nước, Động vật |
| `detail.html` | Chi tiết một tin: breadcrumb, ảnh phóng to, trích dẫn, hộp "Bạn có thể làm gì?", tin liên quan |
| `subscribe.html` | Form đăng ký nhận bản tin (`method="get"` để xem dữ liệu gửi đi trên thanh địa chỉ) |

## Kiến thức sử dụng

| Bài | Áp dụng |
|---|---|
| HTML (bài 2) | `header`, `main`, `article`, `aside`, `footer`, `blockquote`, `ol` / `ul` |
| CSS (bài 3, 4) | Biến màu trong `:root`, viền trái màu cho tiêu đề chuyên mục, `position: sticky` cho cột tin liên quan |
| Flexbox, responsive (bài 5) | Danh sách "Đọc nhiều", tiêu đề chuyên mục, `@media` |
| Bootstrap (bài 6) | Navbar + dropdown, **carousel tin nổi bật**, lưới `row` / `col`, breadcrumb, modal phóng to ảnh |
| Typography (bài 7) | Font có chân (Lora) cho tiêu đề, không chân (Nunito Sans) cho nội dung; tin nổi bật to nhất, tin nhỏ ít chữ |
| Form (bài 8) | `input` email, `select`, `checkbox`, `radio`, `required` |

## Đối chiếu tiêu chí

| Tiêu chí | Thể hiện ở đâu |
|---|---|
| Bố cục chia theo thể loại tin | Mỗi chuyên mục một section, một màu riêng (xanh lá, xanh dương, cam) |
| Hiệu ứng | Hover phóng to ảnh và đổi màu tiêu đề, dropdown chuyên mục, bấm ảnh để phóng to, trang hiện dần |
| Giao diện kiểu CMS | Tin nổi bật, "Đọc nhiều", tin theo chuyên mục, tin liên quan |
| Vấn đề xã hội | Rác thải nhựa, tiết kiệm nước, bảo vệ động vật; mỗi bài có hành động cụ thể cho học sinh |
| Tính năng AI | Chưa có. Học viên có thể trình bày phần dùng AI để gợi ý tiêu đề, tóm tắt tin trong slide |
