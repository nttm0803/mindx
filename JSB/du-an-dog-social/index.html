🐾 Dự án Dog Social – thực hành từng bước

Trang web Dog Social hoàn chỉnh khá dài, nên ta chia thành 6 phần nhỏ. Mỗi bước em làm một phần trong file riêng, kiểm tra đúng rồi mới sang bước tiếp theo. Cuối cùng ghép lại thành một trang.

👉 Xem trang hoàn chỉnh (tab mới) – hãy mở trước để biết mình đang hướng tới điều gì.

0. Chuẩn bị | 1. Thanh menu (Navbar) | 2. Banner (Hero) | 3. Ba tính năng nổi bật | 4. Đánh giá của khách hàng (Carousel) | 5. Bảng giá (3 gói) | 6. Kêu gọi hành động và chân trang | 7. Ghép lại

Bước 0: Chuẩn bị

  1. Tạo thư mục du-an-dog-social chứa index.html và style.css.
  2. Mỗi bước dưới đây làm lần lượt trong cùng index.html; xong bước nào, mở trình duyệt xem bước đó. (Hoặc tạo file riêng buoc-1.html, buoc-2.html… để thử từng phần.)
  3. Chép khung <head> bên dưới và CSS chung vào style.css.
Khung HTML (head + cuối body)
<!DOCTYPE html>
<html lang="vi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Dog Social</title>
    <!-- Phông chữ Google Fonts (cần Internet, không có vẫn chạy bằng phông dự phòng) -->
    <link href="https://fonts.googleapis.com/css2?family=Fredoka:wght@500;600;700&family=Nunito:wght@400;600;700&display=swap" rel="stylesheet">
    <!-- Gắn Bootstrap TRƯỚC -->
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
    <!-- Gắn style.css SAU để CSS của em đè được Bootstrap -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    ... (code các bước) ...

    <!-- JavaScript của Bootstrap: cần cho carousel (bước 4) -->
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>

Vàng – màu nhấn
Navy – chữ, footer
Xanh nhạt – nền

Bảng màu này là phối tương đồng/bổ sung: xanh dương và vàng gần như đối diện nhau trên bánh xe màu, nên nút vàng rất nổi bật trên nền xanh.

Bước 1: Thanh menu (Navbar)

🎯 Mục tiêu: Thanh menu nền xanh: logo bên trái; bên phải là 3 link và nút vàng "Tải ứng dụng". Trên điện thoại, 3 link tự ẩn đi, chỉ còn nút.

▶ Giao diện cần làm (mở tab mới):

Class Bootstrap sẽ dùng

ClassTác dụng
navbarThanh menu
containerGiới hạn chiều rộng, canh giữa
d-flex align-items-center gap-3Xếp ngang, canh giữa, cách nhau
d-none d-md-inlineẨn ở màn nhỏ, hiện từ ≥ 768px
text-white text-decoration-noneChữ trắng, bỏ gạch chân

Hãy tự làm trong file riêng của em trước, rồi mới mở đáp án:

👀 Xem code HTML đáp án
<nav class="navbar nen-xanh py-3">
    <div class="container">
        <a class="navbar-brand text-white fw-bold" href="#">🐾 Dog Social</a>
        <div class="d-flex align-items-center gap-3">
            <a class="link-hover text-white text-decoration-none d-none d-md-inline" href="#tinh-nang">Tính năng</a>
            <a class="link-hover text-white text-decoration-none d-none d-md-inline" href="#danh-gia">Đánh giá</a>
            <a class="link-hover text-white text-decoration-none d-none d-md-inline" href="#bang-gia">Bảng giá</a>
            <a class="btn btn-vang btn-sm fw-bold" href="#">Tải ứng dụng</a>
        </div>
    </div>
</nav>
✏ Thử thách: Thu nhỏ cửa sổ dưới 768px và quan sát 3 link biến mất. Thử đổi d-md-inline thành d-lg-inline. Rê chuột vào link (xem CSS .link-hover:hover ở bước 0): link đổi nền vàng giống một cái nút. Thử đổi var(--vang) thành màu khác.

Bước 2: Banner (Hero)

🎯 Mục tiêu: Nền xanh, chia 2 cột: bên trái tiêu đề lớn + mô tả + 2 nút; bên phải là khung điện thoại với thẻ chú chó. Điện thoại: 2 cột xếp chồng.

▶ Giao diện cần làm (mở tab mới):

Class Bootstrap sẽ dùng

ClassTác dụng
row align-items-center g-5Chia cột, canh giữa theo chiều dọc
col-md-6Mỗi cột chiếm nửa hàng từ ≥ 768px
display-4 fw-boldTiêu đề rất to, đậm
btn btn-outline-lightNút viền trắng
badgeNhãn nhỏ (Poodle, Hiền…)

Bước 4: Đánh giá của khách hàng (Carousel)

▶ Giao diện cần làm (mở tab mới):

Class Bootstrap sẽ dùng

fs-3Cỡ chữ lớn
