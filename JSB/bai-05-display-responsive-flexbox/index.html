1. CSS display

Thuộc tính display quyết định phần tử chiếm chỗ như thế nào trên trang.

a) display: block

Chiếm trọn 1 dòng, phần tử sau bị đẩy xuống dòng mới. Chỉnh được width, height.
Mặc định là block: div, p, h1–h6, ul, li.

2. Responsive website & Media queries

Responsive là website tự thay đổi giao diện cho vừa với mọi màn hình: điện thoại 📱, máy tính bảng 📟, máy tính 💻.

🧠 Dễ hiểu: giống như nước 💧 – đổ vào cốc thì có hình cốc, đổ vào bình thì có hình bình.

Bước 1: Thêm thẻ meta viewport vào head

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Thiếu dòng này, điện thoại sẽ thu nhỏ cả trang máy tính lại, chữ bé tí.

Bước 2: Viết Media queries

Media query = "NẾU màn hình thỏa điều kiện, THÌ áp dụng CSS này".

/* CSS bình thường: áp dụng cho mọi màn hình */
.hop { background-color: blue; }

/* NẾU màn hình rộng TỐI ĐA 768px (≤ 768px) THÌ ... */
@media (max-width: 768px) {
    .hop { background-color: orange; }
}

/* NẾU màn hình rộng TỐI THIỂU 1200px (≥ 1200px) THÌ ... */
@media (min-width: 1200px) {
    .hop { background-color: green; }
}
  • max-width: "nhỏ hơn hoặc bằng" → dùng cho màn hình nhỏ.
  • min-width: "lớn hơn hoặc bằng" → dùng cho màn hình lớn.
  • ⚠ Media query phải viết bên dưới CSS thường để ghi đè được.

Các mốc màn hình (breakpoint) hay dùng

  • 📱 Điện thoại: ≤ 576px
  • 📟 Tablet: 577px – 992px
  • 💻 Máy tính: > 992px

3. Flexbox – Sắp xếp phần tử dễ dàng

Flexbox giúp xếp các phần tử theo hàng hoặc cột, căn giữa, chia đều khoảng cách cực dễ. Chỉ cần thêm display: flex; vào thẻ cha.

  • Flex container: thẻ cha có display: flex.
  • Flex items: các thẻ con trực tiếp, tự động xếp thành hàng ngang.

🧠 Dễ hiểu: Thẻ cha là cái kệ, thẻ con là những quyển sách. Flexbox là cách mình sắp sách trên kệ.

📋 Tóm tắt Flexbox

/* ĐẶT CHO THẺ CHA (container) */
.cha {
    display: flex;
    flex-direction: row;            /* row | row-reverse | column        */
    justify-content: center;        /* căn trục chính (ngang)            */
    align-items: center;            /* căn trục phụ (dọc)                */
    flex-wrap: wrap;                /* cho xuống dòng                    */
    gap: 20px;                      /* khoảng cách giữa các con          */
}

/* ĐẶT CHO THẺ CON (item) */
.con {
    flex: 1;                        /* chia phần chỗ trống               */
}
