1. CSS là gì?

CSS (Cascading Style Sheets) là ngôn ngữ dùng để trang trí trang web: màu sắc, cỡ chữ, khoảng cách, bố cục...

  • 🦴 HTML = bộ khung của ngôi nhà (tường, cửa, phòng).
  • 🎨 CSS = sơn tường, rèm cửa, đồ trang trí.

Cú pháp CSS

selector {
    thuộc-tính: giá-trị;
    thuộc-tính: giá-trị;
}

/* Ví dụ: tô chữ của mọi thẻ h1 thành màu đỏ, cỡ 40px */
h1 {
    color: red;
    font-size: 40px;
}
  • Selector: chọn phần tử nào để trang trí.
  • Thuộc tính (property): muốn đổi cái gì (màu chữ, cỡ chữ...).
  • Giá trị (value): đổi thành gì.
  • ⚠ Nhớ dấu : giữa thuộc tính và giá trị, dấu ; ở cuối mỗi dòng.
  • Chú thích trong CSS viết trong /* ... */

3 cách viết CSS

① Inline: viết trong thuộc tính style của thẻ. (Dòng này màu xanh lá)

② Internal: viết trong thẻ <style> ở phần head. (Dòng này màu tím)

③ External: viết trong file .css riêng, nối bằng thẻ <link>. (Dòng này màu cam)

<!-- ① Inline -->
<p style="color: green;">...</p>

<!-- ② Internal (trong head) -->
<style>
    .vi-du-internal { color: purple; }
</style>

<!-- ③ External (trong head) -->
<link rel="stylesheet" href="style.css">

💡 Nên dùng External: code gọn, 1 file CSS dùng chung cho nhiều trang HTML.

2. Các thuộc tính CSS cơ bản

Về chữ

color: crimson; → đổi màu chữ

font-size: 24px; → đổi cỡ chữ

font-family: 'Courier New', monospace; → đổi phông chữ

font-weight: bold; → chữ đậm

font-style: italic; → chữ nghiêng

text-align: center; → căn giữa chữ

text-decoration: underline; → gạch chân

text-transform: uppercase; → viết hoa toàn bộ

Về hộp (khối)

background-color: lightyellow; width: 300px; height: 80px; border: 3px solid orange;

Cách viết màu

  • Tên màu: red, blue, tomato, gold...
  • Mã HEX: #FF5733 (dấu # + 6 ký tự)
  • RGB: rgb(30, 144, 255) – trộn Đỏ, Xanh lá, Xanh dương (0 → 255)

Đơn vị đo

  • px (pixel): cố định. Ví dụ width: 300px;
  • %: theo phần trăm của thẻ cha. Ví dụ width: 50%; = rộng bằng nửa thẻ cha.

3. CSS Selectors – chọn đúng phần tử

Selector giống như "gọi tên" để CSS biết cần trang trí ai.

  • * → chọn tất cả phần tử.
  • p → chọn theo tên thẻ (mọi thẻ p).
  • .ten-class → chọn theo class (dấu chấm). Nhiều thẻ dùng chung 1 class được.
  • #ten-id → chọn theo id (dấu thăng). Mỗi id chỉ dùng cho 1 thẻ duy nhất.
  • h1, h2 → chọn nhóm (dấu phẩy): áp dụng cho cả h1 và h2.
  • div p → chọn con cháu (dấu cách): chỉ các p nằm bên trong div.

🧠 Dễ nhớ: class giống tên lớp (cả lớp 9A dùng chung), id giống số căn cước (mỗi người 1 số riêng).

Thử nghiệm

Đoạn 1: chỉ là thẻ p bình thường (bị chọn bởi selector .khu-selector p)

Đoạn 2: có class="noi-bat"

Đoạn 3: cũng có class="noi-bat" (class dùng lại được)

Đoạn 4: có id="dac-biet" (duy nhất)

Đoạn 5: có 2 class cùng lúc: class="noi-bat chu-to"

.khu-selector p   { color: gray; }          /* con cháu   */
.noi-bat          { background-color: #FFF3B0; } /* class */
#dac-biet         { color: white; background-color: #6A4C93; } /* id */
.chu-to           { font-size: 22px; }

4. Inspect – "Soi" CSS ngay trên trình duyệt

Công cụ Inspect (DevTools) cho phép xem và sửa CSS trực tiếp trên trình duyệt để thử nghiệm nhanh.

Cách mở

  • Nhấn F12, hoặc
  • Chuột phải vào phần tử → chọn Inspect / Kiểm tra, hoặc
  • Nhấn Ctrl + Shift + C rồi bấm vào phần tử muốn soi.

Các khu vực quan trọng

  • Elements (bên trái): cây HTML của trang.
  • Styles (bên phải): CSS đang áp dụng cho phần tử được chọn.
    • Bỏ tick ☐ để tắt thử 1 thuộc tính.
    • Bấm vào giá trị để sửa (dùng phím ↑ ↓ để tăng giảm số).
    • Bấm vào ô vuông màu để chọn màu bằng bảng màu.
    • Thuộc tính bị gạch ngang là đang bị CSS khác ghi đè.
  • Computed: xem hình Box Model của phần tử (margin, border, padding, content).

⚠ Sửa trong Inspect chỉ là tạm thời. Nhấn F5 là mất! Thấy đẹp thì copy vào file CSS.

🎯 Thử thách

Hộp bí mật 🕵️ – Dùng Inspect đổi màu nền hộp này thành màu vàng, chữ thành cỡ 30px, và tìm xem nó đang có padding bao nhiêu!

5. CSS Box Model – Mọi thứ đều là cái hộp 📦

Trình duyệt coi mỗi phần tử là một chiếc hộp, gồm 4 lớp từ trong ra ngoài:

  1. Content – nội dung (chữ, ảnh). Kích thước = width × height.
  2. Padding – đệm bên trong, giữa nội dung và viền.
  3. Border – viền của hộp.
  4. Margin – khoảng cách bên ngoài, đẩy các hộp khác ra xa.

🧠 Dễ nhớ: Tưởng tượng một bức tranh đóng khung treo tường: bức tranh = content, lớp giấy lót = padding, khung gỗ = border, khoảng tường trống xung quanh = margin.

CONTENT
200px × 60px

🟧 Margin 30px   ⬛ Border 6px   🟦 Padding 20px   ⬜ Content

Tính kích thước thật của hộp

.hop-mau {
    width: 200px;
    padding: 20px;
    border: 6px solid black;
    margin: 30px;
}

Chiều rộng hộp nhìn thấy = width + padding trái + padding phải + border trái + border phải
                         = 200   +   20        +    20        +    6        +    6
                         = 252px

Cách viết tắt padding / margin (theo chiều kim đồng hồ 🕛→🕒→🕕→🕘)

padding: 10px;                /* cả 4 phía 10px                     */
padding: 10px 20px;           /* trên-dưới 10px | trái-phải 20px    */
padding: 10px 20px 30px 40px; /* trên | phải | dưới | trái          */

padding-top: 10px;            /* hoặc viết riêng từng phía          */
margin-left: 20px;

margin: 0 auto;               /* mẹo: căn giữa hộp theo chiều ngang (cần có width) */

Phân biệt Padding và Margin

Padding lớn → nền màu lan rộng ra (vì padding nằm trong hộp)
Margin lớn → hộp bị đẩy ra xa, nền màu không lan ra
