Về mình

Mình bắt đầu thích máy tính từ năm lớp 6 khi làm được trò chơi đầu tiên bằng Scratch. Lên lớp 9, mình muốn tự làm ra thứ mà bạn bè có thể mở xem trên điện thoại, nên đã bắt đầu học lập trình web.

Website này là sản phẩm mình tự làm sau 4 buổi học. Mỗi phần trên trang đều dùng một kiến thức đã học – thử bấm F12 để soi code nhé!

Hành trình học web

  1. Buổi 2 – Làm quen HTML

    Cài VS Code, viết trang web đầu tiên và hiểu website khác webpage thế nào.

  2. Buổi 3 – Tô màu bằng CSS

    Học selectors, box model và cách "soi" trang bằng Inspect.

  3. Buổi 4 – Định vị phần tử

    Hiểu độ ưu tiên, tính kế thừa, và vẽ lá cờ bằng position.

  4. Buổi 5 – Flexbox và Responsive

    Làm trang web tự co giãn đẹp trên cả điện thoại.

  5. Tiếp theo – JavaScript

    Học cách làm cho trang web biết "phản ứng" khi người dùng bấm.
